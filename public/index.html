EL REMATE PERFECTO

Sonidos que se hacen escuchar.

Ponle efecto a cada mensaje con {número}.

60%

Se reproducen en el orden del mensaje. Ejemplo: «Máximo se cayó {58} y despertó en el hospital {45}». Hasta 6 efectos por mensaje; los códigos desconocidos se omiten.

Cargando catálogo de sonidos… Puedes reemplazar cualquier efecto con «Importar audio» (MP3/WAV, máximo 10 segundos y 5 MB). El volumen general también se aplica.

Los archivos se guardan en este navegador y PC. Puedes restablecer la recreación en cualquier momento.

Twitch · chat y seguidores

Se intenta lectura anónima. Si Twitch la rechaza, usa el usuario y su token OAuth con chat:read. No envía mensajes.

Para leer solo a seguidores, el OAuth debe incluir moderator:read:followers y pertenecer al dueño o a un moderador del canal. Si usas una cuenta moderadora, introduce también su usuario y reconecta Twitch.

TikTok · conector no oficial

El streamer debe estar en LIVE. El conector depende de servicios externos y puede requerir una clave Eulerstream o dejar de funcionar si TikTok cambia.

YouTube · API key

Activa YouTube Data API v3 en Google Cloud. Pega la URL del video en directo al conectar. La consulta del chat consume cuota de tu proyecto.

Kick · integración oficial opcional

El chat público funciona sin token ni webhook y sin ser el streamer. Esta alternativa oficial solo se utiliza cuando introduces un token.

1. Crea una app en Kick Developers y habilita webhooks.
2. Expón únicamente /webhooks/kick mediante un túnel HTTPS hacia el puerto 4317.
3. Registra esa URL en tu app y obtén un App Access Token para elegir cualquier canal, o un User Access Token con events:subscribe y channel:read para tu propio canal.
4. Ingresa el token y confirma abajo. El panel se mantiene accesible solo localmente.

El estado será «esperando webhook» hasta recibir un evento firmado.
